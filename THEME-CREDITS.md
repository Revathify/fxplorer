# Theme credits

The optional **iOS-inspired Windows preview** uses original fxplorer controls, icons and Windows Segoe UI fonts. Its Files-style floating sidebar, grid/list browsing, compact navigation and optional inspector were informed by the vault's `Design References/iOS and iPadOS 27` notes. It is not a native Apple implementation and does not bundle Apple Design Resources components, SF Symbols, SF Pro fonts, or the kit's assets. The Apple reference's platform restrictions remain separate from the Pastel kit's license below.

The optional **Pastel UI** theme adapts the colors, rounded surfaces, soft shadows and Nunito typography from **Pastel UI Kit** by **Priyanka Kumari (chefinux)**, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- Original kit: https://www.figma.com/community/file/1255962382215173014/pastel-ui-kit
- Read through Figma MCP from the user's Community copy, cover `301:103` and plants landing page `3:944`, on 2026-10-24.
- Adaptation: the kit's visual treatment is applied to fxplorer's existing Windows file-browser controls and live storage visualization. Product photography, shopping content and the kit's page layouts are not part of the file-browser theme. Existing fxplorer icons remain in use.

Nunito is bundled locally from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/nunito). Its SIL Open Font License is included at `assets/fonts/OFL-Nunito.txt`. No remote fonts or Figma asset URLs are used at runtime.
